# Edge X

`Edge X` قابلیت چندمسیره مقاوم BUB Tunnel برای تونل‌های `Reverse` در شبکه‌های سخت و ناپایدار است.

Edge X چند Carrier مستقل را در یک Tunnel منطقی استفاده می‌کند تا هنگام خراب شدن یا افت کیفیت یک مسیر، ارتباط بتواند سریع‌تر روی مسیر سالم ادامه پیدا کند.

## قابلیت‌های اصلی

- مخصوص حالت `Reverse`
- استفاده از چند Carrier مستقل داخل یک Session منطقی
- `Failover` سریع بین Carrierها
- حفظ Session هنگام تغییر مسیر تا حد ممکن
- محافظت در برابر `Zero-Link`
- بازیابی و پرکردن سریع لینک‌ها
- پشتیبانی از Multipath
- نمایش وضعیت و سلامت Carrierها
- ایزوله بودن از منطق داخلی Transportهای موجود

## خانواده Carrierها

بسته به Build و تنظیمات، Edge X می‌تواند از خانواده‌هایی مانند `TCP/TLS`، `ICMP`، `GRE`، `UDP/KCP` احراز هویت‌شده و `IP-in-IP` استفاده کند.

منطق داخلی Transportهای موجود توسط Edge X بازنویسی نمی‌شود؛ Edge X به‌عنوان لایه Orchestration و Resilience روی آن‌ها عمل می‌کند.

## هدف طراحی

هدف اصلی Edge X کم‌کردن قطع محسوس هنگام افت کیفیت، قطع شدن یا بازگشت مسیرهای شبکه است، بدون قربانی‌کردن سرعت، Latency و پایداری.

جزئیات داخلی مربوط به Scheduler، Authentication، Recovery، Ranking، Session، Replay و Failover عمداً در Repository عمومی مستندسازی نمی‌شوند.
