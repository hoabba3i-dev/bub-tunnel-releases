# 🔀 BUBMIX

[← بازگشت به BUB TUNNEL](../../README.md)

BUBMIX قابلیت مدیریت چند روش انتقال برای تونل‌های **Reverse** است.

این قابلیت چند مسیر تنظیم‌شده را مدیریت می‌کند، وضعیت در دسترس بودن آن‌ها را بررسی می‌کند و هنگام تغییر شرایط شبکه امکان جابه‌جایی خودکار مسیر را فراهم می‌کند.

هر روش انتقال تنظیمات و رفتار مخصوص خودش را حفظ می‌کند.

> مستندات عمومی فقط قابلیت‌های BUBMIX را معرفی می‌کنند و جزئیات داخلی پیاده‌سازی منتشر نمی‌شوند.
