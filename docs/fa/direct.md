# ➡️ آموزش راه‌اندازی Direct

[← بازگشت به BUB TUNNEL](../../README.md)

در حالت Direct ابتدا سمت خارج و بعد سمت ایران را تنظیم کنید.

```text
1. Foreign → Setup Client → Direct
2. Iran    → Setup Server → Direct
```

## سمت خارج

دستور `bub` را اجرا کنید، `Setup Client → Direct` را انتخاب کنید، روش انتقال را انتخاب و تنظیمات کلاینت را کامل کنید.

اگر گزینه چهار لینک نمایش داده شد، با Enter یا `Y` حالت چهار لینک و با `n` حالت تک‌لینک انتخاب می‌شود.

## سمت ایران

دستور `bub` را اجرا کنید، `Setup Server → Direct` را انتخاب کنید و پورت تونل، رمز و تنظیمات سازگار روش انتقال را وارد کنید.
