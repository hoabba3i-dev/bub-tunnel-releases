# 🛠️ مدیریت تونل

[← بازگشت به BUB TUNNEL](../../README.md)

مدیر BUB رابط اصلی مدیریت تونل‌هاست.

کارهای معمول:

- ویرایش
- روشن‌کردن
- متوقف‌کردن
- راه‌اندازی مجدد
- مشاهده لاگ زنده
- حذف
- راه‌اندازی مجدد زمان‌بندی‌شده

بخش‌های اصلی تنظیمات شامل اتصال، روش انتقال، تنظیمات مخصوص روش انتقال و تنظیمات پیشرفته تونل هستند.
