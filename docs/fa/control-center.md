# 🧭 راهنمای کنترل سنتر

[← بازگشت به BUB TUNNEL](../../README.md)

کنترل سنتر لایه مدیریت متمرکز BUB Tunnel است و از طریق پنل وب و ربات تلگرام امکان مدیریت سرورها و تونل‌ها را فراهم می‌کند؛ مخصوصاً زمانی که دسترسی مستقیم SSH مناسب یا در دسترس نیست.

## قابلیت‌های مهم

- ساخت و مدیریت تونل از پنل وب یا ربات تلگرام
- روشن، خاموش، راه‌اندازی مجدد، ویرایش و حذف سرویس‌های تونل از راه دور
- مدیریت چند سرور ایران و خارج از یک کنترل سنتر
- مانیتورینگ زنده و جداگانه هر دو سمت
- نمایش ترافیک، سرعت، اتصال‌ها، زمان فعالیت، پردازنده، حافظه، پینگ، نوسان و از دست رفتن بسته‌ها
- تست سرعت داخل تونل و لاگ زنده هر سمت
- مدیریت BUBMIX و مشاهده وضعیت مسیرها
- محدودیت ترافیک سمت سرور و عملیات زمان‌بندی‌شده
- مرکز سلامت و هشدارهای عملیاتی
- پشتیبان‌گیری رمزگذاری‌شده، بازیابی و Disaster Recovery
- جایگزینی سرور از دست‌رفته بدون ساخت دوباره همه تونل‌ها
- انتقال کنترل سنتر با Restore Code
- پشتیبانی از HTTPS و PWA
