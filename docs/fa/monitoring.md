# 📊 مانیتورینگ زنده

[← بازگشت به BUB TUNNEL](../../README.md)

بخش مانیتورینگ اطلاعات عملیاتی مهم را نمایش می‌دهد، از جمله:

- زمان فعالیت
- اتصال‌های فعال
- ترافیک دانلود و آپلود
- سرعت فعلی و بیشینه
- مصرف پردازنده و حافظه
- تعداد اتصال مجدد
- پینگ سمت مقابل
- نوسان پینگ
- از دست رفتن بسته‌ها
- بررسی دسترسی بیرونی
- سلامت تونل

## محدودیت مصرف

برای تونل می‌توان سقف مصرف، مقدار استفاده‌شده، باقی‌مانده، درصد مصرف و رفتار توقف خودکار را مشاهده و مدیریت کرد.
