# 🚀 آموزش نصب

[← بازگشت به BUB TUNNEL](../../README.md)

برای نصب آخرین نسخه پایدار از نصب‌کننده رسمی استفاده کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/hoabba3i-dev/bub-tunnel-releases/main/install.sh | bash
```

بعد از نصب، مدیر برنامه را اجرا کنید:

```bash
bub
```

بسته‌های عمومی برای Linux AMD64 و Linux ARM64 ارائه می‌شوند.

## شروع کار

دستور `bub` را اجرا کنید، جهت تونل را انتخاب کنید و سپس تنظیمات روش انتقال موردنظر را کامل کنید.
