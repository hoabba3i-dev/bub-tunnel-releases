# ➡️ Direct Setup

[← Back to BUB TUNNEL](../../README.md)

For Direct tunnels, configure the **Foreign Client first**, then the **Iran Server**.

```text
1. Foreign → Setup Client → Direct
2. Iran    → Setup Server → Direct
```

## Foreign Client

Run `bub`, choose `Setup Client → Direct`, select the required transport, and complete Client configuration.

If asked to enable 4-link multipath striping, press Enter or choose `Y` for four bonded links, or `n` for a single link.

## Iran Server

Run `bub`, choose `Setup Server → Direct`, and use the corresponding tunnel port, token, and compatible transport settings.
